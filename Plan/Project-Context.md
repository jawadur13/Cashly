# Cashly - Project Context

Cashly is a modern personal finance and expense tracking web application.

## Tech Stack

* Framework: Next.js (App Router)
* Backend: Appwrite
* Database: Appwrite Database
* Authentication: Appwrite Email & Password Authentication
* Deployment: Vercel
* Design: Responsive, mobile-first, installable as a PWA

## Phase 1 Features

### Authentication

* Register
* Login
* Forgot Password
* Email Verification
* Change Password
* Profile Settings

### Dashboard

* Current Balance
* Monthly Income
* Monthly Expense
* Monthly Savings
* Recent Transactions
* Expense by Category Chart

### Transactions

* Add Transaction
* Edit Transaction
* Delete Transaction
* Income & Expense Types
* Search
* Filter by Date
* Filter by Category
* Filter by Account

### Accounts

* Multiple Accounts (Cash, Bank, bKash, Nagad, etc.)
* Add/Edit/Delete Account
* Account Balance

### Categories

* Default Categories
* Custom Categories
* Add/Edit/Delete Category

### Budgets

* Monthly Budget
* Category Budget
* Budget Progress

### Reports

* Monthly Summary
* Yearly Summary
* Income vs Expense
* Category Breakdown

### Data

* CSV Export
* CSV Import

### User Experience

* Dark/Light Mode
* Responsive Design
* PWA (Installable)
* Toast Notifications
* Loading Skeletons
* Empty States
